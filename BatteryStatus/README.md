# Battery Status

Battery Status is an iOS app that shows both live battery information and deeper battery health details extracted from Apple analytics reports.

It combines:

- live battery state from the device
- battery system data such as level, charging state, thermal state, and low-power mode
- battery health metrics from exported analytics files
- a simple workflow for importing analytics data from the Files app

## Features

- View current battery charge percentage and state
- See device and system information such as iOS version and thermal state
- Import analytics files exported from iPhone Settings
- Inspect battery health details like maximum capacity and cycle count
- Review daily metrics such as average temperature and voltage ranges
- Choose a folder of analytics files and automatically load the newest valid one

## How it works

The app reads:

1. live iOS battery data from `UIDevice`
2. analytics data files generated by iOS under the device’s analytics reports

The analytics file contains extra battery information that the public iOS APIs do not expose directly, such as cycle count and capacity data.

## Requirements

- Xcode
- An Apple silicon or Intel Mac
- An iPhone or iOS simulator for testing
- The app must be run on a device or simulator with Apple’s battery APIs available

## Setup

1. Open the Xcode project in `BatteryStatus.xcodeproj`.
2. Select your development team and target device/simulator.
3. Restore any Swift packages if prompted.
4. Build and run the app.

## Using the app

### Import analytics data

To get battery health details from the app:

1. Open Settings on your iPhone.
2. Go to Privacy & Security → Analytics & Improvements.
3. Make sure Share iPhone Analytics is enabled.
4. Tap Analytics Data.
5. Select the newest file from the list (for example, `Analytics-YYYY-MM-DD-...`).
6. Tap the Share button and choose Save to Files.
7. Save the file into a folder such as `BatteryLogs`.
8. In the app, tap Choose analytics folder and select that folder.

The app will load the newest suitable analytics file in that folder and display the available battery data.

## Notes

- Apple creates analytics files only periodically, so battery report data may update once a day.
- The app tries recent analytics files and uses the first valid battery report it finds.
- Analytics files may contain device identifiers and carrier information, so do not share them publicly.
